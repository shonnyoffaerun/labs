## Инструкция по запуску

Требуется Python версии 3.11+. Все команды выполняются в папке с проектом.

### Шаг 1. Создание и активация виртуального окружения

Создайте окружение: `python3 -m venv venv`

Активируйте:
- На линукс / макос:
  `source venv/bin/activate`
- На виндовс (👎):
  `устанавливайте линукс`

### Шаг 2. Установка зависимостей

В папке с проектом выполните: `pip install -r requirements.txt`

### Шаг 3. Запуск программы

Также в папке, запустите: `python main.py` _(из-за нашего разделения по файлам, запускным файлом является **main.py**, а не **lab2.py**, имейте ввиду :^)_

Что делает программа:
1. Загружает 360-и документов и проверяет отсутствие пропусков и дубликатов.
2. Запускает базовый поиск по совпадению слов.
3. Сравнивает 4 конфигурации TF-IDF (A — сырой текёст, B — с лемматизацией, C — без стоп-слов, D — с добавлением пар слов/биграмм).
4. Определяет лучшую конфигурацию
5. Разбирает на понятных примерах, почему базовый поиск и сырой текст ошибаются, и почему биграммы снизили точность.
6. Сохраняет результаты в файлы experiment_metrics.csv и search_results.csv.

### Шаг 4. Запуск сайта (Streamlit)

Чтобы проверить работу поиска в веб-интерфейсе, выполните: `streamlit run app.py`

В браузере откроется страница на локальном адресе http://localhost:8501. В боковой панели можно менять конфигурацию поиска, а в строке ввода — писать любой запрос и сразу видеть карточки ТОП 5 найденных экспонатов.
